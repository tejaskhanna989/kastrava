Kast Manager.
Your system, at a glance.

A fresh, minimal system companion with a dark neon interface. Live dashboard, sortable processes with kill, hand-drawn graphs, disk usage and a file browser — written from scratch in C with GTK4.

Install from Snap View source

Linux · GTK4 / libadwaita · C · GPLv3

Everything you need. Nothing you don't.

Kast Manager 2.x is written from scratch — no GNOME System Monitor code. Just a fast, dark, ad-free companion for your machine.

Live dashboard

Stat cards for CPU, memory, processes and uptime — updating in real time at a glance.

Sortable processes

Searchable, sortable process list with End and Kill actions. Find and stop anything instantly.

Hand-drawn graphs

Smooth, custom-rendered CPU and memory graphs — no heavyweight charting libraries.

File systems

See usage across every mounted partition with clean, readable bars.

File browser

Navigate, open, create folders and trash — a minimal file manager built right in.

Terminal UI

A companion TUI for when you're already in the shell and want the same data.
