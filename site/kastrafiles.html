KastraFiles.
Files, the fast way.

A lightweight, responsive file manager engineered natively for Wayland and Hyprland. macOS-style Miller columns, buttery kinetic scrolling, and an AES-256 secure vault — all GPLv3 and free.

Download View source

Linux · Wayland · Qt6 / QML · GPLv3

Built for the keyboard.

Everything about Kastrafiles is tuned for speed and flow — from the three-column layout to encrypted storage that feels like any other folder.

Miller columns

macOS Finder-style multi-column browsing. Every level stays visible — no more back button archaeology.

AES-256 secure vault

Encrypt files and folders with AES-256. Your vault mounts like a normal directory and locks with one key.

Kinetic scrolling

Buttery-smooth momentum scrolling that keeps up with trackpads and high-refresh displays.

Keyboard-driven

Full shortcuts for navigation, actions and vault control. Your hands never have to leave home row.

Theming

Fully customizable appearance to match your desktop — down to the glass and compositor effects.

Wayland-native

Engineered for Wayland and Hyprland with deep compositor integration — not a ported X11 app.
